# Publication provenance

The original working tree had no Git repository, branches or remotes. R8 constructs a separate
sanitized snapshot; it does not rewrite or replace prior history. The R7 source and all22 existing
review ZIP archives are retained outside the public repository with recorded SHA256 checksums.
R5's verified archive remains available as a separate historical baseline. No milestones are
silently mixed. R7's runtime is the preferred candidate, subject to fresh release acceptance.

The public source checkpoint retains application, migrations, scenarios, tests, frontend and
historical verification helpers. Only publication documentation/configuration and a private-host
scanner literal are changed initially. The R4 baseline audit/store needed by differential tests
are included. Private logs, database files, virtual environments, caches, historical ZIPs and
generated frontend bundles are excluded. Historical screenshots are attributed to their actual
R5 execution. No third-party stock assets were added.

The LICENSE remains byte-identical: copyright2026, all rights reserved. The owner's R8 mandate
explicitly authorizes this GitHub publication; it does not authorize a new software license.
Dependency license inventory and the exact public-tree safety scan are recorded with release
evidence. Only the sanitized single-root publication history will be pushed.
