# Security and local-lab boundary

RAILSTORM is a synthetic research preview. It provides no production authentication, custody,
compliance certification, bank connectivity or real-money guarantees. Keep services on loopback
and the database on its private Compose network. Do not deploy the supplied stack publicly.

Do not put real customer data, credentials or financial accounts into scenarios, screenshots,
issues or test databases. Report suspected vulnerabilities privately through GitHub's private
vulnerability reporting if available; otherwise request a private contact channel without posting
exploit details or secrets in a public issue. No response-time SLA is promised.

Pinned dependencies improve reproducibility but require continuing security review. Historical
acceptance is not proof of current dependency security. Updates require new regression and
financial/recovery verification before release.
